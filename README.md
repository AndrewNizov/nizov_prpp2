# nizov_prpp2
Для хранения товаров я использовал "ArrayList", потому что он позволяет добавлять товары в нужном порядке и не удаляет повторяющиеся записи. Чтобы убрать одинаковые товары, я использовал "LinkedHashSet". Он удаляет повторы, но сохраняет порядок, в котором товары были добавлены. Для группировки товаров по категориям и подсчёта товаров от разных поставщиков я выбрал "TreeMap", так как с ним названия автоматически располагаются по алфавиту. Сами товары внутри категорий хранятся в "ArrayList".

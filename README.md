# nizov_prpp2
Для хранения исходных данных использован "ArrayList", так как он сохраняет порядок добавления элементов и позволяет хранить повторяющиеся записи. Для удаления дубликатов выбран "LinkedHashSet", который сохраняет порядок первого появления товаров. Для группировки товаров и подсчёта позиций по поставщикам используется "TreeMap", поскольку он автоматически сортирует ключи по алфавиту. В качестве значений в группировке используется "ArrayList", позволяющий хранить список товаров каждой категории.
